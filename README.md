# Retention incentive evaluation

A small, reproducible impact evaluation demo in two parts.

1. **Can observational methods recover a known causal effect?** On the public LaLonde / NSW
   job training data, five estimators are compared against the answer from a randomised
   experiment, with bootstrap intervals, balance tables and overlap plots.
2. **How would I evaluate a retention bonus?** A pre-analysis plan for a hypothetical,
   randomised retention bonus pilot for a critical staff group: randomisation, power, primary
   outcome, follow-up, risks of side effects and a decision rule. The planned analysis
   (including a Kaplan-Meier and Cox survival view) is run on **simulated data** to show that
   it works.

A one page decision brief in Danish is generated from the same run
([brief/beslutningsoplaeg.md](brief/beslutningsoplaeg.md), also as HTML). It separates
*Hvad data viser*, *Sandsynlige forklaringer* and *Hvad vi endnu ikke har belæg for*, and
states expected effect, resource need, feasibility and risk.

## What is real and what is simulated

| Part | Data | Status |
|---|---|---|
| `causal/` | NSW experimental sample (185 treated, 260 randomised controls), PSID (2,490) and CPS (15,992) survey controls, Dehejia and Wahba (1999) version | **Real**, public, 1970s US data |
| `design/` | staff, units, exits, bonus amount, effect size | **Simulated** or assumed; labelled in every file |
| `brief/` | section 1 uses the real NSW results; everything about a bonus pilot is an assumption or simulated | mixed, labelled in the brief |

No Forsvaret data, no Danish register data and no real experiment were used.

### What the NSW comparison shows

* A naive comparison with survey controls gets the sign wrong. The people who joined the
  programme were very different from the average PSID or CPS respondent before it started.
* Adjusting for prior earnings and demographics brings most estimates near the benchmark,
  because selection into NSW ran mainly through observed prior earnings and unemployment.
  On PSID, OLS and nearest neighbour matching still miss: OLS extrapolates over controls with
  no counterpart among the treated, and matching rests on a small set of reused controls and
  swings with the propensity score specification.
* "Near" is weak here. The observational intervals are wider than the effect, a different
  but equally reasonable propensity score specification shifts estimates substantially, and
  IPW on PSID leans on a handful of heavily weighted controls. Without the experiment there
  would be no way to tell which adjusted estimate to trust. That is the argument for
  randomising a retention bonus instead of comparing those who stay with those who leave.

### What the simulated pilot shows

* Under the planning assumptions, the pilot needs individual randomisation within strata.
  Randomising whole units would need a far larger effect to be detectable with the same
  number of people (figures in the results block above).
* A bonus paid at month 12 can postpone exits rather than prevent them. The simulation builds
  in such a spike; the pre-specified harm check and the split Cox model at month 12 detect it,
  while a single pooled hazard ratio and the global proportional hazards test do not.
* The simulated numbers only show that the analysis recovers effects that are known by
  construction. They say nothing about how a real bonus would work.

## How to run

Requirements: [uv](https://docs.astral.sh/uv/), Python 3.11 or later, R 4.x with `jsonlite`
(`foreign` and `survival` ship with R). The full run takes about 1.5 minutes on an 8 GB M1.

```bash
make all      # causal estimates, simulated pilot, R cross-check, documents
make check    # ruff, pytest, documents match the run outputs
make site     # static site in site/
```

The three raw data files are cached in `data/raw/` and verified against SHA-256 digests in
`src/rie/data.py`; if one is missing it is downloaded from
<https://users.nber.org/~rdehejia/data/> and checked.

Layout:

| Path | Content |
|---|---|
| `src/rie/data.py` | download, checksum, sample construction |
| `src/rie/estimators.py` | difference in means, OLS, propensity score matching, IPW, AIPW (all for the ATT), bootstrap, balance |
| `src/rie/causal.py` | runs every estimator on every sample, writes `causal/` |
| `src/rie/pilot.py` | power and MDE, stratified randomisation, simulation, planned analysis, survival |
| `src/rie/report.py` | generates every document that contains numbers; `--check` fails if one is stale |
| `r/crosscheck.R` | benchmark, Welch CI, IPW (PSID and CPS) and the simulated Cox HR, recomputed in R from the raw files |
| `tests/` | offline tests on the cached data and on simulations with known answers |

## CI and CD

* `ci.yml`: ruff (lint and format), pytest, a check that every generated document matches
  the committed outputs, and an R job that reruns `r/crosscheck.R` and compares it with
  Python.
* `cd.yml`: on push to `main`, after CI passes, reruns the whole pipeline from the raw data,
  rebuilds the documents, prints PDF of the brief and deploys the site to GitHub Pages.

Both workflows are validated locally with `actionlint`; they have not run on GitHub yet.

## Limitations

* NSW is one programme, in one country, fifty years ago, with 185 treated people. That the
  adjusted estimates land near the benchmark here does not show they would elsewhere.
* The bootstrap interval for nearest neighbour matching is not theoretically valid (Abadie
  and Imbens 2008); it is shown for comparison only.
* One propensity score specification is used for both samples, chosen before looking at
  the estimates; Dehejia and Wahba tuned theirs per sample, so the numbers differ from theirs
  for the observational samples.
* Every pilot parameter (baseline retention, effect size, ICC, bonus size, the post payment
  spike) is an assumption. The replacement cost of a leaver, which decides whether a bonus
  pays off, is not estimated at all.
* No real personnel data, no Danish register data and no real experiment.

## Use of AI

The code, tests, documents and the Danish brief were drafted with Claude Code (an AI coding
assistant) to a specification I wrote. Checks that do not depend on trusting that output:
the experimental benchmark reproduces the published 1,794 USD; an independent R
implementation reproduces the benchmark, IPW and Cox numbers; tests on simulated data with
known effects; and every number in the documents is generated from the run, with CI failing
if a document drifts from the outputs.
